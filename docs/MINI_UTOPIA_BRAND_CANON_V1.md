# Mini Utopia Brand Canon v1.0

## Brand role

Mini Utopia should look like one coherent creative game, not a collection of Streamlit screens.

The brand system is intentionally soft, playful, block-built, collectible, and child-friendly.

## Logo system

### Primary horizontal logo

Use at:
- main page header
- Home
- Character Factory
- future Mini World Factory
- Stories
- covers and presentation headers

Structure:
- Mini Utopia wordmark
- star / tiny-world icon language
- tagline: **Travel Around Every World**

### Square badge

Use at:
- top of Streamlit sidebar
- app/avatar contexts
- compact cards
- future image corner marks
- future video watermark

The square mark must remain readable at small sizes.

## Typography Canon

### Display / headings
- English: Fredoka
- Chinese: ZCOOL KuaiLe
- fallback: Noto Sans SC / rounded system sans

Use for:
- page titles
- buttons
- navigation
- hero headings
- short labels

### Body / UI
- English: Nunito
- Chinese: Noto Sans SC

Use for:
- descriptions
- forms
- profile data
- longer explanatory text

Do not introduce unrelated decorative fonts into Canon UI.

## Color family

Core UI tokens:
- Strawberry Pink #F7B7D2
- Mint #B9E7D0
- Lavender #D7C2F3
- Sky Blue #BDE3F7
- Peach #F8CBAE
- Cream #FFF4D7
- Ink #2D3150

Rules:
- high lightness
- low-to-medium saturation
- soft gradients
- generous white/cream breathing room
- avoid neon-heavy color and large pure-black areas

## UI shell

Sidebar:
- square badge at the top
- compact tagline under the badge
- soft cream/lavender/sky gradient
- rounded navigation rows
- playful but uncluttered spacing

Main shell:
- primary horizontal logo before page content
- translucent soft brand surface
- consistent rounded cards
- pill-like controls and gentle shadows

## Brand and generated media

The application should render the official logo as a real brand asset.

Image-generation models must not invent or redraw the logo.
Generated Character / World art stays text-free where possible; branding is composed by the application afterward.

## Change control

Logo, typography, and core brand colors are Canon.

Changes require an explicit Brand Canon version bump.
