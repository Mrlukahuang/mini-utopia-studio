# Mini Utopia · Original CC0 Background Music (V1-W2-01)

Three **original, procedurally composed** short instrumental loops, produced for this repo under the project owner's CC0-music request. **Not** Kenney, KayKit or OpenGameArt recordings.

Source: original algorithmic note/chord arrangements and generated wave synthesis in this project. Intended dedication: **Creative Commons CC0 1.0 Universal** (https://creativecommons.org/publicdomain/zero/1.0/). The project owner requested CC0 music for family/private movies. No identifiable human voices, child recordings, samples, downloaded copyrighted stems, AI voice-clone or external APIs were used.

The songs can be used independently, modified, shortened or looped. They are deliberately lightweight and kid-safe. The backend must only accept IDs from `studio.family_music_catalog.MUSIC_TRACKS`; never interpret a saved film's music field as a URL or an arbitrary local filepath.

This source asset slice only embeds and validates the WAV files. FFmpeg mixing and the Director selector are separate acceptance steps; do not claim an audible exported MP4 until ffprobe/ffmpeg tests pass.
